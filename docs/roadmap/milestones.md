# Milestones — breakdown by phase

Each phase is a **demonstrable** increment of the [walking skeleton](index.md), not an isolated
module. The rule: a phase is *done* when its criterion can be **verified with a command** (build,
test, curl, benchmark) — never "by vibes" (per the [observability](../architecture/observability.md)
discipline and the [OKRs](okrs.md)). Each phase leaves the system **running**, just more capable.

> **Global status:** design/architecture phase essentially closed (ADR-0000..0007 accepted).
> Next: **Phase 0 → 1** (contracts + walking skeleton). Phases are numbered the same as in the [roadmap index](index.md).

---

## Phase 0 — Contracts
**Objective:** prove that a Go struct governs HTTP + OpenAPI with no magic.
**Built:** Go module; [Huma](../components/huma-api.md) over chi; typed `ChatRequest`/`ChatResponse`;
`POST /v1/tenant/{tenant_id}/chat` endpoint (stub response); autogenerated `/openapi.json`; healthcheck.
**Definition of done:**
- [ ] `go build ./...` exits 0.
- [ ] The server boots; `curl /openapi.json` returns valid OpenAPI 3.1 derived from the struct.
- [ ] Invalid input (violates the struct) → structured 422, without touching the handler.
- [ ] The path's `tenant_id` reaches the `ctx` (a trace log shows it).

**Touches:** Huma. **Doesn't need:** LLM, API keys, DBs.

## Phase 1 — Walking skeleton
**Objective:** the thinnest working end-to-end flow, with real TTFT.
**Built:** [Gollem](../components/gollem-orchestrator.md) integration; an LLM call with
structured output against the Phase 0 struct; **SSE** streaming; `ctx` cancellation.
**Definition of done:**
- [ ] A message travels Huma → Gollem → LLM → SSE and the client sees tokens streaming (measurable TTFT).
- [ ] Reflection loop demonstrated: given an injected invalid JSON, it re-requests and corrects within ≤ N retries.
- [ ] Closing the request cancels the `ctx` → the LLM call is cut off (verified by token logs).
- [ ] One [OTel](../architecture/observability.md) Span per interaction with `gen_ai.usage.*`.

**Touches:** Huma, Gollem, observability. **Needs:** an LLM provider's credentials.
**Covers:** [OKR O1](okrs.md#o1--the-single-contract-works-phase-0-1).

## Phase 2 — Working memory
**Objective:** the context window never grows unbounded.
**Built:** in-process [BadgerDB](../components/badgerdb-working-memory.md); `tenant:user:session` buffer;
async Summary Buffer past N messages.
**Definition of done:**
- [ ] Session read/write in BadgerDB < 1 ms (benchmark).
- [ ] Summary buffer reduces input tokens ≥ 50% over a long session.
- [ ] A 30-turn conversation maintains coherence with bounded context.

**Touches:** BadgerDB. **Covers:** [OKR O2](okrs.md#o2--working-memory-compresses-without-losing-coherence-phase-2). **Enables:** [Bet 6](../research/bet-06-bits-per-token-metric.md) (measuring bits/token with and without memory).

## Phase 3 — Facts memory
**Objective:** the system remembers across sessions (Engram pattern).
**Built:** [rqlite](../components/rqlite-facts-memory.md) + FTS5; async fact extraction when the
session closes; `Relevance × Importance × Recency` scoring; supersede.
**Definition of done:**
- [x] Async fact extraction writes to the facts store (via the Outbox worker; SQLite default, rqlite backend behind `RQLITE_URL`).
- [x] FTS5 retrieves the top 3-4 engrams by score (Relevance × Importance × Recency).
- [x] Supersede test: a new fact archives/degrades the old one.

**Touches:** rqlite ([ADR-0004](../decisions/0004-facts-memory-rqlite-vs-litefs.md)).
**Covers:** [OKR O3](okrs.md#o3--the-system-remembers-across-sessions-phase-3).
**Enables:** [Bet 1](../research/bet-01-surprisal-gated-memory.md) (surprisal gate over these facts).

---

## Phase 4 — Semantic memory
**Objective:** RAG isolated per tenant, zero leakage.
**Built:** [Qdrant](../components/qdrant-semantic-memory.md) with payload filtering in HNSW;
local reranker ([ADR-0006](../decisions/0006-reranker-cohere-vs-bge-local.md), BGE-v2-m3); UUID v5 idempotency.
**Definition of done:**
- [x] Isolation test: tenant A never sees tenant B's vectors.
- [x] Reranking trims injected context to ≤ 4 fragments while maintaining relevance.
- [x] Reprocessing the same message doesn't duplicate vectors (deterministic UUID v5).

**Touches:** Qdrant, reranker. **Covers:** [OKR O4](okrs.md#o4--rag-isolated-per-tenant-phase-4).

---

## Phase 5 — Consistency
**Objective:** if a node goes down mid-way, memory converges instead of corrupting.
**Built:** [Transactional Outbox](../architecture/consistency.md) in BadgerDB; async workers with
exponential backoff; cold-boot reconciliation.
**Definition of done:**
- [x] Outbox: message + event in the same local ACID transaction in BadgerDB (`AppendWithOutbox`).
- [x] Crash test: close/reopen of the file-backed store keeps pending events; at-least-once retry on a failing sink loses nothing (a literal `kill -9` chaos test is future work).
- [x] Cold boot drains orphaned `outbox:pending:*` entries on startup (`RecoverOutbox`).

**Touches:** BadgerDB, rqlite, Qdrant, consistency. **Covers:** [OKR O5](okrs.md#o5--consistency-under-failure-phase-5).

## Phase 6 — Sleep cycle
**Objective:** the agent is smarter the next day, without touching the core.
**Built:** Rust worker with [DataFusion](../components/datafusion-sleep-cycle.md)
([ADR-0005](../decisions/0005-datafusion-go-rust-boundary.md), batch subprocess); dedup, contradictions,
noise cleanup; primitive self-improvement.
**Definition of done:**
- [x] DataFusion runs in the sleep cycle (Rust subprocess, ADR-0005), produces dedup + cleanup, and the dropped rows are deleted from the live store.
- [ ] Friction detection triggers a rewrite of a primitive per `user_id`. *(Deferred — needs a per-user primitives store that does not exist yet.)*
- [x] An `agent.optimization.*` OTel event per mutation (auditable).

**Touches:** DataFusion, rqlite, Qdrant. **Covers:** [OKR O6](okrs.md#o6--offline-self-improvement-phase-6).
**Enables:** [Bet 1](../research/bet-01-surprisal-gated-memory.md), [Bet 2](../research/bet-02-working-memory-codec.md) (run in this worker).

## Phase 7 — Granular control (enterprise-ready)
**Objective:** security × cost × behavior, ready for multi-tenant enterprise.
**Built:** full [granular control](../architecture/granular-control.md) — rate limiting + circuit
breaker, scope-based tools, dynamic prompt; physical multi-tenancy ([ADR-0007](../decisions/0007-multitenancy-fisico-db-unica-vs-por-tenant.md), hybrid/tiered).
**Definition of done:**
- [x] Per-tenant rate limiting with a clean 429 (token bucket in BadgerDB, checked before the LLM call; concurrency-tested). Model degradation at 95% quota is future work.
- [x] Tools injected according to scopes: without permission → the primitive doesn't exist for the LLM (`internal/tools`).
- [x] Circuit breaker on the LLM client (opens on repeated provider failures; half-open recovery).
- [~] Cost per token per tenant via OTel Span (`gen_ai.usage.*` captured; a dashboard is not built).
- [ ] Distroless binary < 50 MB, startup < 1 s, idle RAM < 50 MB (everything except Qdrant). *(Not yet measured.)*

**Touches:** everything. **Covers:** [OKR O7](okrs.md#o7--ready-for-enterprise-phase-7).
