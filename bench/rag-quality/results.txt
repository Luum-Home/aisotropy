  cross_en_to_es   en query -> es corpus : Cross-lingual: English question retrieves the parallel Spanish paragraph.

The two cross_* slices are the multilingual proof: an EN query must find the
parallel ES paragraph (and vice-versa) with no lexical overlap to lean on. Only
an embedder that maps both languages into one shared space scores above chance.

-- honest gap (generic public benchmark != aisotropy's real RAG) -------------
XQuAD is a Wikipedia QA benchmark: clean, single-relevant, professionally
translated paragraphs. aisotropy's real workload is multi-tenant conversational
MEMORY — noisy turns, distilled facts, per-user isolation, several relevant
chunks per query. These numbers measure the EMBEDDER + STORE on a generic task;
they do NOT yet measure retrieval over aisotropy's own conversational corpus. A
domain gold set (labeled tenant memories) is the next step. This moves retrieval
from UNMEASURED to MEASURED on a real, licensed, multilingual benchmark.
