# Vireo F2 Freight Sled
The Vireo F2 is the uncrewed freight sled used on the Marrow Loop. Each F2 has four container cradles, carries no passengers and has no seats at all, and reaches a service top speed of 268 km/h. The F2 shares the "Wren" control computer family with the passenger Vireo T7 but runs a freight-only firmware branch built at Kessler Works.
