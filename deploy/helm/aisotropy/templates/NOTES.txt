WARNING: {{ int $replicas }} replicas with session affinity OFF. Working memory is
per-process (embedded BadgerDB, internal/memory) — a request that lands on a
replica which never served that user gets NO conversation history and answers
from a cold context. That is a wrong answer, not an error: the client sees no
signal. Set --set sessionAffinity.enabled=true (needs ingress.enabled and an
ingress-nginx controller) or run one replica. See values.yaml for what affinity
does and does not cover.
{{- end }}

Reach the API (port-forward):

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "aisotropy.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}

  curl -s localhost:{{ .Values.service.port }}/healthz   # liveness  -> {"status":"ok"}
